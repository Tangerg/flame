# Runtime documentation

Runtime documentation describes only the current system.

- [`ARCHITECTURE.md`](ARCHITECTURE.md) defines product ownership, dependency direction, execution, persistence, protocol, and lifecycle boundaries.
- [`../contract/API_REFERENCE.md`](../contract/API_REFERENCE.md) is the generated human-readable operation index.
- [`../contract/manifest.json`](../contract/manifest.json), [`../contract/openrpc.json`](../contract/openrpc.json), and [`../contract/schema.json`](../contract/schema.json) are the machine-readable Runtime Protocol truth.
- [`../AGENTS.md`](../AGENTS.md) contains mandatory module rules.
- [`../../DEVELOPMENT.md`](../../DEVELOPMENT.md) defines verification, live DeepSeek checks, dependency discipline, and reference-project use.

Implementation history, completed plans, capability ledgers, retrospectives, competitive research, and duplicated protocol prose belong in Git history, not the active architecture baseline.
