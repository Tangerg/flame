# Model catalog admission

`Selections` applies the same released Scope catalog facts for Runtime and
independent feature authors. Reasoning effort must match the exact known model's
advertised levels. Media input must match its accepted modalities. This package
performs no provider I/O and never supplies another provider or model.

A catalog miss remains admissible because compatible endpoints may expose private
models. The configured Runtime/provider remains their execution authority; catalog
absence does not establish model availability or invent token limits. The default
Scope catalog remains the single source of published model facts.
