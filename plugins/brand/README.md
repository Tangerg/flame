# Brand identity

This optional settings component presents the canonical `@flame/brand-assets`
artwork and color. It has no backend, private store or Runtime business commands.
Its installed module embeds each original PNG. Saving decodes those same bytes
and uses the captured component's public `saveFile` collaborator.

The host owns the destination, transfer result and cancellation lifetime.
Disablement withdraws the settings entry through the ordinary installation
lifecycle. The product's application icon and empty-conversation companion remain
ordinary consumers of the shared asset owner.
