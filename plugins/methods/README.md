# Project Methods

Install and enable Methods on a Runtime. Open a project, expand its Background
section, and choose Methods. Save the change instruction, two independent review
instructions, and the exact model. Choose a managed worktree to run the saved
version. Create worktrees from the Worktrees view.

The execution keeps its version, Runtime store, worktree, base commit and original
handoff. The change Run uses workspace tools and can use the Runtime Plan tools
when Plans is selected. The review Run delegates two read-only checks. Each check
keeps its original Run and the final evidence. A report becomes available for
human approval after both checks pass. Open either phase's conversation to answer
its pending questions.

The Methods view retains the original report and decision. Reject a report to keep its evidence and decision while releasing the worktree
for another execution. A changed handoff requires a fresh review. Saving a new version leaves active executions bound to
the version selected at admission.
